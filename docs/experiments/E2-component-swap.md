# E2 — 구성 요소 바꿔 끼우기: 격차 중 가치 평가·정책이 차지하는 몫 (사전 등록)

등록: 실행 전. 본문은 실행 뒤 바꾸지 않는다. 결과·이탈은 맨 아래 절에만 덧붙인다. E1/E1' 결과와 무관하게 실행한다 (조건부 아님).

## 1. 질문과 추정 대상

같은 탐색(우리 현재 탐색, 노드 고정)에서 가치 평가와 정책을 각각 Rapfi NNUE 의 것으로 바꾸면, Rapfi NNUE 상대 점수가 얼마나 변하는가.

2×2 칸: 가치 V ∈ {우리(C3), NNUE} × 정책 Π ∈ {우리(C3), NNUE}.
- **가치 주효과** = ½[(V=NNUE,Π=우리) − (V=우리,Π=우리)] + ½[(V=NNUE,Π=NNUE) − (V=우리,Π=NNUE)] (Elo)
- **정책 주효과** = 같은 방식으로 Π 에 대해
- **상호작용** = (NN,NN) − (NN,우리) − (우리,NN) + (우리,우리)
- **남은 격차** = (V=NNUE,Π=NNUE) 칸의 Elo (0 이면 Rapfi 와 같음). 평가·정책을 Rapfi 것으로 바꿔도 남는 차이 = 탐색 구조·기능 차이 몫.

판정 경계는 두지 않는다. 추정치와 95% 구간만 보고하고, 문장은 E1' 와 같은 두 종류만 쓴다.

## 2. 조건

- **우리 탐색:** 등록 커밋 시점 기본값, 노드 고정 40k (노드 수에는 정지 탐색 노드 포함). 탐색 구조·가지치기·연장·전술 표시(공격/방어 비트)는 네 칸 모두 같다.
  바뀌는 것은 evaluate() 가 돌려주는 값과 generateScored() 의 정책 점수뿐이다.
- **NNUE 가치 → 우리 점수:** wr = win + draw/2 (NNUE 출력, 둘 차례 관점), 점수 = scale·ln(wr/(1 − wr)), wr 는 [1e-4, 1 − 1e-4] 로 자른다.
  scale = 우리 모델의 scale (C3 와 같은 척도). 즉승·막을 수 없는 쌍사 같은 정확한 판정(leafProbe)은 네 칸 공통으로 유지한다.
- **NNUE 정책 → 우리 정책 점수:** 점수 = round(256·ln p), p = NNUE 정책 softmax 확률. 우리 정책 정수는 "로짓 × 256" (engine/eval.hpp 의 qp 정의)이라
  정책 간격 컷·실현 확률 깊이가 같은 단위로 동작한다.
- **상대:** Rapfi NNUE 4000n (E1 과 같은 버전·가중치·설정, 해시는 E1' 2절과 같음), 노드 고정이라 결정적이다.
- **오프닝:** E1' 의 묶음 A 와 같은 200 오프닝, 칸당 400판 (4프로세스 × 50쌍). 네 칸이 같은 오프닝 (대응 설계). 모든 판 --save 저장.
- **정지 규칙:** 고정 표본, 중간 분석·확장 없음. E1' 4절과 같은 규칙.

## 3. 선행 관문

- **G1 = E1' 의 G1** (Rapfi 패치 동등성). 같은 결과를 공유한다.
- **G3 어댑터 정확성:**
  (a) 루트에서 어댑터 evaluate() 를 위 변환식으로 되돌린 승률이 Rapfi 의 evaluateValue 와 1e-4 이내로 같다 (300국면).
  (b) 무작위 수순 make/undo 1,000회 뒤 evaluate()·정책 점수가 처음과 같다.
  (c) V=우리, Π=우리 칸의 지문(evaltool fingerprint 와 같은 300국면·20k 노드)이 현재 엔진과 같다 → 어댑터가 기본 경로를 바꾸지 않음.
  하나라도 실패하면 고친 뒤 처음부터 다시 검증한다.

## 4. 분석

- 칸 점수 → Elo = −400·log10(1/s − 1).
- 구간: 오프닝 단위 부트스트랩 (오프닝을 복원 추출해 네 칸의 해당 판을 함께 뽑는다, 2,000회, 백분위 95%). 주효과·상호작용·남은 격차 모두 같은 부트스트랩 표본으로 계산한다.
- 예상 해상도: 칸 400판의 이항 95% 폭 ±4.5%p. 주효과는 두 차이의 평균이라 대응 상관에 따라 이보다 좁거나 비슷할 것이고, 실제 폭을 그대로 보고한다.

## 5. 알려진 한계

- 노드 고정이므로 NNUE 의 계산 비용(노드당 시간이 훨씬 큼)을 일부러 무시한다. 이 결과는 "지식의 몫"이지 실전 이득이 아니다.
- NNUE 값은 Rapfi 의 탐색에 맞춰 학습된 것이고 우리 탐색의 가지치기 문턱(정적 문턱·역방향 가지치기 여유 등)은 C3 척도에 맞춰 정했다.
  변환식이 척도를 맞추지만, 문턱과의 상호작용 때문에 NNUE 가치의 몫이 과소 추정될 수 있다.
- 남은 격차에는 Rapfi 탐색의 구조 차이와 함께 "같은 노드 수"의 정의 차이(두 엔진의 노드 계수 방식)가 섞인다.
