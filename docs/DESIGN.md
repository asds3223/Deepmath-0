# DCE — Rapfi NNUE 판단을 증류한 순수 고전 오목 엔진

15×15 프리스타일, 싱글코어, 폰더링 없음.
실행 중에는 신경망이 없습니다. 패턴 판별과 점수표 조회만으로 평가합니다(Yixin식 고전 엔진).
점수표 값은 Rapfi 25(태그 `250615`, mix9svq NNUE)의 판단을 정답으로 삼아 자동으로 채웠습니다.

## 1. 구성


## 2. 평가 (C3)

**위협 단계(줄 단위):** 칸 c 에 자기 돌을 놓는다고 가정하고, c 를 지나는 9칸 창에서 "c 를 포함한 5목의 완성점 개수"로 정의합니다.

| 단계 | 정의 |
|---|---|
| FIVE | 바로 5목 |
| OPEN4 | 완성점 2곳 이상 |
| FOUR | 완성점 1곳 |
| OPEN3 / THREE | 한 수 더 두면 OPEN4 / FOUR |
| OPEN2 / TWO / ONE / DEAD | 그보다 먼 단계 |

4방향 단계의 조합(495종)에서 칸 등급 14종을 정합니다.

**가치 (로짓, 초반/후반 2벌을 진행도로 보간):**

| 표 | 내용 |
|---|---|
| CS / CO | 빈칸의 자기/상대 조합 코드 |
| J | 같은 칸의 자기 등급 × 상대 등급 |
| SH | 빈칸 주변 3×3 모양 (D4 대칭 동치, 8,740종) |
| INIT | 자기 최고 등급 × 상대 최고 등급 |
| CNT | 등급별 개수 버킷 |
| PSQ, BIAS, PH | 돌 위치, 둘 차례 색, 진행도 |

**정책 (수 정렬과 깊이 소모에 사용):**
- 조합 코드, 3×3 모양, 전역 전술 등급 × 칸 등급, 직전 수 거리와 9×9 상대 좌표
- 줄 모양 원형, 상대 좌표 × 등급, 전술 등급 × 조합 코드, 직전 수가 놓인 줄 위의 응수

**증분 처리:**
- 착수 때 패턴이 바뀌는 칸(4방향 ±4, 최대 33칸)의 기여만 정수로 빼고 더합니다.
- 비용: 평가 0.03µs, 수 생성 약 2µs, 두기+무르기 약 0.9µs.
- `test_incremental`이 전체 재계산과 반올림 오차 이내로 일치하는지 검증합니다.

**학습:**
- 정답은 Rapfi NNUE 정적 승률(BCE)과 NNUE 정책(softmax CE)입니다.
- 데이터는 교사 롤아웃, 섭동, 형제 국면, 탐색 리프로 약 1,700만 국면입니다.

## 3. 탐색 (기본값 = 1,000판 A/B로 튜닝한 값)

| 요소 | 내용 |
|---|---|
| 수 생성 | 즉승 → 그 한 수. 상대 4 → 막기만. 상대 4-3/승리 4 위협 → 위협을 실제로 없애는 수 + 맞받기 4만 (줄 키 하나로 판정) |
| 정렬 | TT → 킬러 → 반박수 → 히스토리 + 정책 |
| 깊이 소모 | 실현 확률 깊이(정책 1위와의 로짓 차이) + 로그형 늦은 수 감축. 둘을 더함 |
| 가지치기 (비전술 수) | 정책 간격 컷, 남은 깊이별 조용한 수 예산, 정적 문턱 |
| 노드 단위 | 역방향 정적 가지치기(d ≤ 5), 내부 반복 감축, improving 신호 |
| 정지 탐색 | 기준값 + 4 만들기, 상대 4는 막기 (최대 4수) |
| 리프 판정 | 즉승, 막을 수 없는 쌍사는 정확한 메이트 점수 |
| 시간 | 한도의 75%가 지나면 다음 반복을 시작하지 않음 |

## 4. 주요 실험 결과 (요약)

**효과 있음:**

| 변경 | 결과 |
|---|---|
| 3×3 모양 표 (탐색 없는 판단 대결) | 대 NNUE 21.5% → 27.0% |
| 정책 확장 (C → C2) | top-8 91.8% → 94.4% |
| 역방향 정적 가지치기 + 감축 가산 | +60 Elo |
| 정지 탐색 6수 → 4수 | +19~24 Elo |
| 시간 사용 50% → 75% | +22 Elo |
| 증분 평가·후보 비트셋 | 약 50만 → 85만 노드/s |

**효과 없음 또는 해로움:**

| 시도 | 결과 |
|---|---|
| VCF 정지 탐색 | 1초에서 −55 Elo |
| 루트 VCT 탐색기 | 100ms에서 −23 Elo |
| Rapfi식 수 개수 가지치기 | 전술 수를 앞에 둬도 −90~−121 Elo |
| 탐색 결과로 가치 학습 | +2~13 Elo |
| 균형 가중, 형제 순위 손실 | 0 |
| 데이터 3배 | 0 |

**Rapfi 기능 끄기 실험** (Rapfi 고전 모드, 기능별 400판, 우리 승률 상승폭):

| 끈 기능 | 우리 승률 변화 |
|---|---|
| 수 개수 가지치기 | +19%p |
| LMR | +11%p |
| 퓨틸리티 | +6.5%p |
| 나머지 | 0~5%p |

**현재 성적** (같은 시간, 200판):

| 상대 | DCE 승률 |
|---|---|
| Rapfi 고전 모드 | 36.5% |
| Rapfi NNUE 500노드 | 49% |
| Rapfi NNUE 4,000노드 | 17.5% |

## 5. 작업 방법
- **빌드와 테스트:** `scripts/build.sh` 후 `build/test_ab`, `build/test_board`, `build/test_incremental`
- **리팩터링 검증:** `build/evaltool fingerprint --model models/c3.dce --data data/tac.bin --nodes 20000 --limit 300`. 해시가 같아야 동작이 같다는 뜻입니다.
- **설정 비교:** `scripts/ab.sh "이름" 12 "--a-rfpDepth 4" ""` (1,000판, 오차 약 ±3%p)
- **Windows 배포:** `scripts/build_windows.sh` → `dist/pbrain-dce.exe` (AVX2, 가중치 내장)

## 6. 주의
- Rapfi(GPL-3)는 오라클로만 링크합니다. `engine/`에는 Rapfi 코드가 없습니다.
- 고정 버전: Rapfi `250615`, 가중치 `rapfi-networks@918b757` (`scripts/fetch_rapfi.sh`).
- `data/`(학습 데이터, 약 3GB)와 `third_party/`는 커밋하지 않습니다.
